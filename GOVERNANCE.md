# Governance

The system separates source context from implementation output.

- Source-backed facts live in `context/`, `source-docs/`, and manifests.
- Generated implementation values live in `design-system/`.
- Token JSON is canonical; generated CSS is derivative.
- Missing source evidence is labeled as a gap, not invented.
- Public assets must remain synthetic or explicitly safe to publish.
- AI output requires human review before being treated as approved design direction.
- Validation must pass before handoff.
