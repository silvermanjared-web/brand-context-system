# AI Operating System Reference

This repository applies the portfolio's shared AI operating-system pattern to context engineering and design implementation.

The canonical reference lives in [Growth Architecture OS](https://github.com/silvermanjared-web/growth-architecture-os/tree/main/04-ai-systems/ai-operating-system-reference).

Local mapping:

- **context** → structured brand, voice, source, code, Figma, and asset inputs;
- **capability** → extraction, validation, token generation, and review;
- **authority** → source-backed facts only; missing evidence stays a gap;
- **execution** → token generation and deterministic validation;
- **evidence** → manifests, example extraction, generated tokens, and tests.

The system demonstrates that reliable AI-assisted design starts with structured context, not a clever prompt.
