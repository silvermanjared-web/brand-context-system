# Selected Front-End Files Manifest

> Purpose: The curated list of front-end files worth reviewing for the demo extraction.

## Why a manifest

A full repo can contain many files. This manifest keeps the design-system extraction focused on the files that actually show brand, layout, component, and token patterns.

## Selected files

| # | File path | Why it matters | Copied to subfolder? |
|---|-----------|----------------|----------------------|
| 1 | `selected-frontend-subfolder/sample-landing-page.html` | Shows page structure, hero, cards, CTAs, review panel, and navigation | yes |
| 2 | `selected-frontend-subfolder/sample-styles.css` | Shows color values, spacing, radius, shadows, typography, buttons, and card treatment | yes |

## Selection criteria

- Files that expose color, type, spacing, radius, or shadow decisions.
- Reusable components that set the visual language.
- One representative page or template per major layout type.
- Files that encode a brand rule in code.

## Review output

The selected files should support a token candidate table, component inventory, layout pattern summary, and gap list.
