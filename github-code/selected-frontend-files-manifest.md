# Selected Front-End Files Manifest

> Purpose: The curated list of front-end files worth reviewing — not the whole repo. Copy the actual files into `../selected-frontend-subfolder/` and index them here.

## Why a manifest

A repo can have thousands of files. This manifest tells an AI agent exactly which files matter for understanding the design language, and why. Keep it tight: 5–25 files, not 500.

## Selection criteria

- Files that define **tokens** (color, type, spacing).
- **Reusable components** that set the visual language.
- **One representative page/template** per major layout type.
- Anything that encodes a **brand rule in code** (e.g., a theme config).
