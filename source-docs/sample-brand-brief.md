# Sample Brand Brief

This is a public-safe mock source document for the Northstar Growth Studio demo brand.

## Situation

The brand needs a reusable context bundle that can help a designer, engineer, or AI assistant understand the system before producing tokens, components, or front-end work.

## Audience problem

Marketing and design teams often begin implementation with scattered inputs:

- voice notes in one place
- Figma files in another
- code samples in another
- asset folders without manifests
- unclear review rules
- no documented source precedence

That creates inconsistent output and repeated re-explanation.

## Brand promise

Northstar Growth Studio turns scattered marketing and design context into usable operating structure.

## Message hierarchy

1. Context comes before execution.
2. Source-of-truth discipline prevents drift.
3. Reusable standards make work easier to review.
4. AI tools need structured inputs, not vague prompts.

## Proof cues

Use structural proof, not inflated claims:

- source file inventory
- asset manifest
- extraction target specification
- review checklist
- validation script
- example output

## Review warning

Do not invent metrics, customer names, logos, licensed fonts, or real client outcomes. This brief is a demo source document.
